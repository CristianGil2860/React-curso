# ⚡ React Vibe Code — Plataforma Educativa

Bienvenido al portal oficial del curso de **React Vibe Code**, desarrollado con **React 19**, **JavaScript** y **Vite**.

---

## 🧭 Secciones de la Aplicación

La aplicación cuenta con una barra de navegación con 4 vistas principales:

1. **🏠 Inicio (Home):** Presentación del curso, llamado a la acción y resumen de los 4 módulos de estudio.
2. **📚 Documentación de React:** Temas esenciales con explicaciones claras y snippets de código:
   - *¿Qué es JSX?*
   - *Componentes y Props*
   - *Estado con useState*
   - *Efectos secundarios con useEffect*
   - *Renderizado de Listas (`.map`) y Condicionales*
3. **💻 Guía de Inicio y Comandos Básicos:**
   - Flujo paso a paso para crear un proyecto desde cero con Vite.
   - Tabla interactiva de comandos frecuentes (`npm run dev`, `npm run build`, etc.) con botones de copiado.
   - Estructura y anatomía de carpetas de un proyecto React.
4. **🚀 Proyecto de Ejemplo para Alumnos (Vibe Study Tracker):**
   - Mini-aplicación funcional de gestión de metas de estudio.
   - Progreso dinámico en porcentaje calculado con JavaScript.
   - Modo "Ver Código Fuente Explicado" para que los alumnos aprendan cómo fue programado.

---

## ⚡ Comandos para el Alumno

- **Servidor de desarrollo:** `npm run dev` ➔ Disponible en [http://localhost:5173/](http://localhost:5173/)
- **Compilar para producción:** `npm run build`
- **Previsualizar producción:** `npm run preview`
